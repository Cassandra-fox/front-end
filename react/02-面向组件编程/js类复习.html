总结

1.类是对象的模板，对象是类的实例。
2.类的定义使用 class 关键字，类名首字母大写。
3.类中包含构造器方法 constructor 和一般方法。
4.构造器方法用于初始化实例对象的属性。
5.一般方法定义在类的原型对象上，共享给所有实例对象。
6.使用 new 关键字创建类的实例对象。
7.类支持继承，子类使用 extends 关键字继承亲类。
8.子类必须调用 super() 方法调用亲类的构造器方法。
9.子类可以重写亲类的方法，实现多态性。
10.类的静态方法使用 static 关键字定义，不能被实例对象调用。

类中方法this指向

1.普通函数：undefined
2.箭头函数：定义时所在上下文的this
3.构造函数：实例对象
4.事件处理函数：undefined
