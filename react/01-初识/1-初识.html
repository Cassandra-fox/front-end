React

用于构建用户界面的 JavaScript 库。
由 Facebook 在 2013 年发布。
1.组件化模式，提高开发效率和代码复用性。
JSX 语法，JavaScript 和 HTML 混写。
2.声明式编码，编码人员无需直接操作 DOM，提高开发效率。
3.使用虚拟 DOM 和优秀的 diff 算法，提高性能。
4.React Native 用于移动端开发。

JSX

JavaScript XML 的缩写，是一种类似 XML 的 JavaScript 语法扩展。
1.可以在 JavaScript 代码中直接编写 HTML 结构。
2.可以使用大括号 {} 在 JSX 中嵌入 JavaScript 表达式。
3.JSX 代码会被 Babel 转换为纯 JavaScript 代码。
4.JSX 语法更接近 HTML，易于理解和使用。
5.JSX 可以提高代码的可读性和维护性。

XML早期用来存储和传输数据
1.可扩展性：XML 允许用户定义自己的标签，具有良好的可扩展性。
2.自描述性：XML 数据具有自描述性，易于理解和解析。
3.平台无关性：XML 是纯文本格式，可以在不同平台之间传输。

JSON
1.轻量级：JSON 格式简洁，占用空间小，传输效率高。
2.易于解析：JSON 格式易于解析和生成，许多编程语言都支持 JSON。
3.与 JavaScript 兼容：JSON 是 JavaScript 的子集，可以直接在 JavaScript 中使用。
4.广泛应用：JSON 广泛应用于 Web 开发中的数据交换。

虚拟DOM和真实DOM

1.真实 DOM 是浏览器中的 DOM 树，操作真实 DOM 会导致页面重绘和回流，性能较低。
2.虚拟 DOM 是 React 内部维护的一棵轻量级的 JavaScript 对象树，表示 UI 的结构。
3.当状态改变时，React 会先更新虚拟 DOM，然后通过 diff 算法计算出最小的变更集，最后批量更新真实 DOM。
4.使用虚拟 DOM 可以减少对真实 DOM 的操作，提高性能。
5.虚拟 DOM 的概念使得 React 能够实现高效的 UI 更新和渲染。

组件与模块

组件：是构建用户界面的独立、可复用的代码块。
1.组件可以包含自己的状态和生命周期方法。
2.组件可以通过 props 接收外部数据。
3.组件可以嵌套使用，构建复杂的 UI 结构。
4.组件化开发提高了代码的可维护性和复用性。
模块：是指将代码分割成独立的文件或单元，每个模块封装特定的功能或逻辑。
1.模块可以导出变量、函数或类，供其他模块使用。
2.模块化开发有助于组织代码，避免命名冲突。
3.ES6 引入了原生的模块系统（import/export），使得模块化更加方便。
4.模块化有助于提高代码的可维护性和可测试性。
