1.函数提升

函数提升（Function Hoisting）是 JavaScript 中的一个行为特性，指的是在代码执行前，函数声明会被提升到其所在作用域的顶部。这意味着无论函数在代码中出现的位置如何，它们都可以在声明之前被调用。

需要注意的是，函数调用和函数表达式（Function Expression）不会被提升。只有函数声明（Function Declaration）会被提升。

2.函数参数

动态参数

JavaScript 中的函数可以接受任意数量的参数。通过 arguments 对象，可以访问所有传入的参数。

默认参数

ES6 引入了默认参数的概念，可以为函数参数设置默认值。

剩余参数

剩余参数（Rest Parameters）允许将不定数量的参数表示为一个数组。通过在参数前添加三个点（...），可以将所有剩余参数收集到一个数组中。

展开运算符

展开运算符（Spread Operator）允许将数组或对象展开为多个元素。通过在数组或对象前添加三个点（...），可以将其展开。

典型使用场景：求数组最大值/最小值，合并数组，合并对象等。

3.箭头函数

箭头函数（Arrow Function）是 ES6 引入的一种新的函数定义方式。它使用更简洁的语法来定义函数，并且不绑定自己的 this 值。

使用场景：替代匿名函数

基本语法

箭头函数的基本语法如下： 

const functionName = (parameters) => {
  // function body
};

与普通函数的区别

1. 语法更简洁：箭头函数省略了 function 关键字和大括号（如果只有一行代码）。

2. 不绑定 this：箭头函数不会创建自己的 this 值，而是继承外部函数的 this 值。
DOM 事件处理函数中不建议使用箭头函数，因为 this 不指向触发事件的元素。
