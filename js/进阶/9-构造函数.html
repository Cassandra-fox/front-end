构造函数

深入对象

创建对象三种方式：

  • 字面量方式
  • new Object()方式
  • 构造函数方式

构造函数

一种特殊的函数，用来初始化对象。快速创建多个类似对象。

使用new关键字调用函数的行为成为实例化。
实例化构造函数时没有参数可以省略（）
构造函数内部无需return语句，默认返回this对象。写了return也没用。
new Object ,new Array ,new Date等都是实例化构造函数

实例化执行过程

  1. 创建一个新对象
  2. 将构造函数的作用域赋给新对象（this指向新对象）
  3. 执行构造函数中的代码（为新对象添加属性）
  4. 返回新对象

构造函数创建的对象彼此独立，互不影响。

实例成员和静态成员

实例成员：通过构造函数创建的对象是实例对象，实例对象中的属性和方法称为实例成员。
静态成员：构造函数的属性和方法称为静态成员。
静态成员通过构造函数本身调用，实例成员通过实例对象调用。
静态成员通常用来存储类的共有信息，实例成员用来存储每个实例对象的独有信息。

内置构造函数

JavaScript提供了一些内置的构造函数，用于创建特定类型的对象。常见的内置构造函数有：

  • Object：创建对象
  • Array：创建数组
  • Date：创建日期对象
  • RegExp：创建正则表达式对象
  • String：创建字符串对象
  • Number：创建数字对象
  • Boolean：创建布尔对象

js底层会对简单数据类型进行包装，创建临时对象来调用方法，调用完毕后销毁这个临时对象。

Object

三个静态方法：Object.create()、Object.keys()、Object.values()

  • Object.create(proto)：创建一个新对象，指定其原型为proto
  • Object.keys(obj)：返回一个数组，包含对象自身的所有可枚举属性名
  • Object.values(obj)：返回一个数组，包含对象自身的所有可枚举属性值
  • Object.assign(target, ...sources)：将所有可枚举属性从一个或多个源对象复制到目标对象

Array

forEach()、map()、filter()、reduce()等常用方法

  • forEach()遍历数组：不返回数组，对数组的每个元素执行一次提供的函数
  • map()迭代数组：返回新数组，包含通过调用提供的函数处理过的每个元素
  • filter()过滤数组：创建一个新数组，包含所有通过测试的元素
  • reduce()累计器：返回累计处理的结果，对数组中的每个元素执行一个 reducer 函数，最终计算出一个值

reduce执行过程

  1. 初始化累加器：reduce()的第二个参数作为初始值
  2. 遍历数组：对数组中的每个元素执行 reducer 函数
  3. 更新累加器：reducer 函数返回值作为下一个元素的累加器
  4. 返回最终结果：遍历完成后返回累加器的最终值

其他方法

  • find()：返回数组中第一个满足条件的元素
  • some()：检测数组中是否至少有一个元素满足条件
  • every()：检测数组中是否所有元素都满足条件
  • join()：将数组元素连接成一个字符串
  • slice()：返回数组的一个片段，不修改原数组
  • from()：将类数组对象或可迭代对象转换为数组

String

toUpperCase()、toLowerCase()、charAt()、indexOf()等常用方法

  • toUpperCase()：将字符串转换为大写
  • toLowerCase()：将字符串转换为小写
  • charAt(index)：返回指定位置的字符
  • indexOf(substring)：返回子字符串在字符串中首次出现的位置，找不到返回-1
