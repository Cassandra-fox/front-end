对象

一种数据类型，引用数据类型。
一种无序的数据集合。

声明： let 对象名 = {属性名1:属性值1,属性名2:属性值2,...};

let 对象名 = new Object();
对象名.属性名 = 属性值;

对象由属性和方法组成。
属性：对象的特征，描述对象的状态。
方法：对象的行为，描述对象可以执行的操作。

使用对象：
增删改查
访问属性：对象名.属性名 或 对象名['属性名']
修改属性：对象名.属性名 = 新值 或 对象名['属性名'] = 新值
添加属性：对象名.新属性名 = 属性值 或 对象名['新属性名'] = 属性值
删除属性：delete 对象名.属性名 或 delete 对象名['属性名']
遍历属性：for...in循环
for (let key in 对象名) { console.log(key + ': ' + 对象名[key]); }

对于多词属性或属性名包含特殊字符的属性，必须使用[]访问

方法

方法是对象的行为，是对象可以执行的操作。
方法的声明：
let 对象名 = {属性名1:属性值1,方法名1: function() { // 方法体 },...};
方法的调用：对象名.方法名() 或 对象名['方法名']()
方法内部可以使用this关键字来引用当前对象。

数学内置对象

js内部提供的对象，可以直接使用，无需声明。
Number对象：提供数字相关的属性和方法。

Math对象：提供数学常数和函数。
Math.PI：圆周率
Math.abs(x)：返回x的绝对值
Math.ceil(x)：返回大于等于x的最小整数，取整
Math.floor(x)：返回小于等于x的最大整数，取整
Math.round(x)：返回四舍五入后的整数
Math.max(a,b,...)：返回一组数中的最大值
Math.min(a,b,...)：返回一组数中的最小值
Math.random()：返回0到1之间的随机小数，包括0但不包括1
Math.sqrt(x)：返回x的平方根
Math.pow(x,y)：返回x的y次幂

注意：Math对象的方法都是静态方法，不能通过new Math()创建实例
Math对象的属性和方法都是只读的，不能修改

随机数
生成指定范围的随机整数：Math.floor(Math.random() * (max - min + 1)) + min
生成指定范围的随机小数：Math.random() * (max - min) + min

补充

关键字：
保留字:目前没有意义，但将来可能会具有特殊意义的单词。int,short,long
标识（标识符）：用于标识变量、函数、属性等的名称，必须遵循一定的命名规则

基本数据类型：undefined、null、boolean、number、string、symbol
在存储变量时，基本数据类型直接存储值
引用数据类型：object（对象）、array（数组）、function（函数）
在存储变量时，引用数据类型存储的是地址（引用）

栈和堆：
栈：存储基本数据类型的值，存储空间小，存取速度快。由操作系统自动分配和释放内存
堆：存储引用数据类型的值，存储空间大，存取速度慢。由程序员手动分配和释放内存，若程序员不释放，由垃圾回收机制自动回收
栈和堆的区别：存储内容不同，存取速度不同，存储空间不同
