事件监听

事件：用户与页面交互时发生的事情，比如点击、加载、输入等。
事件监听：监听某个事件的发生，并在事件发生时执行相应的代码。
常见的事件类型：click（点击）、mouseover（鼠标悬停）、mouseout（鼠标移出）、keydown（按键按下）、keyup（按键释放）等。
事件监听器：用于注册事件监听的函数，可以使用addEventListener方法添加

语法

element.addEventListener(event, handler);
element：要监听事件的DOM元素
event：要监听的事件类型
handler：事件发生时执行的函数

路辰

事件监听版本

DOM L0 事件源.on事件=function(){}
这种方式只能绑定一个事件处理函数，后绑定的会覆盖先绑定的。
DOM L2 事件源.addEventListener(事件,处理函数)
可以绑定多个事件处理函数，互不影响。

鼠标事件

click：点击
dblclick：双击
mouseover/mouseenter：鼠标悬停
mouseout/mouseleave：鼠标移出
mousedown：鼠标按下
mouseup：鼠标释放

焦点事件

表单获得光标
focus：获得焦点
blur：失去焦点

键盘事件

keydown：按键按下
keyup：按键释放
keypress：按键按下并保持

文本事件

input 用户输入事件

事件对象

事件对象包含了事件的相关信息，比如事件类型、触发事件的元素、鼠标位置等。
在事件处理函数中，可以通过参数获取事件对象。
例如：element.addEventListener('click', function(event) { // event是事件对象 })
