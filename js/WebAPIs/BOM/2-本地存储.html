本地存储

HTML5引入了两种本地存储机制：localStorage和sessionStorage。
数据存储在用户浏览器中，不会随页面刷新或关闭而丢失。
容量较大，一般为5MB左右。
localStorage用于在浏览器中存储数据，数据没有过期时间，除非手动删除，否则数据会一直保存在浏览器中。
sessionStorage用于在浏览器会话期间存储数据，数据在浏览器窗口关闭后会被删除。
本地存储的优点是可以在客户端存储大量数据，减少服务器请求，提高性能。缺点是数据存储在客户端，可能存在安全风险。
本地存储只能存储字符串类型的数据，如果需要存储其他类型的数据，需要先将其转换为字符串类型，例如使用JSON.stringify()方法将对象转换为JSON字符串。
使用localStorage和sessionStorage的常用方法有：setItem()、getItem()、removeItem()和clear()。
例如，使用localStorage存储一个键值对：
localStorage.setItem('key', 'value');
获取存储的值：
var value = localStorage.getItem('key');
删除存储的值：
localStorage.removeItem('key');
清空所有存储的值：
localStorage.clear();

localStorage

可以将数据永久存储在本地，除非手动删除，否则数据不会过期。
可以多窗口共享数据。
以键值对的形式存储数据，键和值都是字符串类型。

localStorage的常用方法：
setItem(key, value)：存储数据
getItem(key)：获取数据
removeItem(key)：删除数据
clear()：清空所有数据

sessionStorage

可以将数据临时存储在本地，数据在浏览器窗口关闭后会被删除。
只能在同一窗口中共享数据。
以键值对的形式存储数据，键和值都是字符串类型。

sessionStorage的常用方法：
setItem(key, value)：存储数据
getItem(key)：获取数据
removeItem(key)：删除数据
clear()：清空所有数据

本地存储复杂数据

本地存储可以存储复杂数据，例如对象和数组。需要使用JSON.stringify()将数据转换为字符串，获取时使用JSON.parse()将字符串转换回对象。

数组map方法

map()方法创建一个新数组，其结果是该数组中的每个元素调用一个提供的函数后返回的结果。
语法：array.map(function(currentValue, index, arr), thisValue)
currentValue：当前元素的值
index：当前元素的索引
arr：当前元素所属的数组
thisValue：可选参数，传递给函数的值
返回值：一个新数组，数组中的元素是原始数组调用函数处理后的值
例如，将一个数字数组中的每个元素都乘以2：
const numbers = [1, 2, 3, 4];
const doubled = numbers.map(num => num * 2);
console.log(doubled); // 输出: [2, 4, 6, 8]

数组join方法

join()方法将数组中的所有元素转换为一个字符串，并返回这个字符串。
语法：array.join(separator)
separator：可选参数，指定用于分隔数组元素的字符串。如果省略，默认使用逗号（,）作为分隔符。
返回值：一个字符串，表示数组中的所有元素连接在一起，中间用指定的分隔符分隔。
例如，将一个字符串数组中的所有元素连接成一个字符串：
const words = ['Hello', 'world', 'this', 'is', 'JavaScript'];
const sentence = words.join(' ');
console.log(sentence); // 输出: "Hello world this is JavaScript"

渲染页面思路

使用map遍历数组处理数据生成tr，返回一个新数组。
使用join将新数组转换为字符串。
将生成的字符串插入到table的tbody中。
