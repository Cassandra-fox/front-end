正则表达式

正则表达式（Regular Expression，简称regex或regexp）是一种用于匹配字符串中字符组合的模式。它们通常用于字符串搜索和替换操作。
正则表达式由普通字符（如字母和数字）以及特殊字符（称为元字符）组成，这些元字符具有特定的含义和功能。
在js中，用来验证表单输入、搜索字符串、替换字符串等。

语法

正则表达式可以通过两种方式创建：字面量语法和RegExp构造函数。
字面量语法：
const regex = /pattern/flags;
RegExp构造函数：
const regex = new RegExp('pattern', 'flags');
其中，`pattern`是要匹配的字符串模式，`flags`是可选的修饰符，用于控制匹配行为。常见的修饰符包括：
g：全局搜索，匹配所有符合条件的子串
i：忽略大小写
m：多行模式

常用方法

  • test()：测试字符串是否匹配正则表达式，返回布尔值。
  • exec()：执行匹配操作，返回一个数组或null。
  • match()：在字符串中查找匹配的子串，返回一个数组或null。
  • replace()：替换匹配的子串，返回新的字符串。
  • search()：搜索匹配的子串，返回第一个匹配项的索引或-1。
  • split()：根据匹配的子串拆分字符串，返回一个数组。

元字符

元字符是正则表达式中的特殊字符，它们具有特定的含义和功能。

边界符：
^：匹配输入字符串的开始位置
$：匹配输入字符串的结束位置

量词：用来设定某个模式出现的次数
*：匹配前面的子表达式零次或多次
+：匹配前面的子表达式一次或多次
?：匹配前面的子表达式零次或一次
{n}：匹配前面的子表达式恰好n次
{n,}：匹配前面的子表达式至少n次
{n,m}：匹配前面的子表达式至少n次，但不超过m次。逗号左右不能有空格

字符类：
[...]：定义一个字符类，匹配方括号内的任意一个字符
[^...]：定义一个否定字符类，匹配不在方括号内的任意一个字符
^[]$:匹配其中一个字符并且只能有一个
|：表示“或”操作，匹配左侧或右侧的子表达式
()：定义一个子表达式，用于分组和捕获
字符类(预定义)：
.：匹配除换行符外的任何单个字符
\d：匹配任何数字字符，等价于[0-9]
\D：匹配任何非数字字符，等价于[^0-9]
\w：匹配任何字母、数字或下划线字符，等价于[A-Za-z0-9_]
\W：匹配任何非字母、数字或下划线字符，等价于[^A-Za-z0-9_]
\s：匹配任何空白字符（空格、制表符、换行符等）
\S：匹配任何非空白字符
