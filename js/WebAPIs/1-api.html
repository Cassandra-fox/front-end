Web APIs基本概念

Web APIs是浏览器提供的一组接口，允许开发者与浏览器的功能进行交互。它们涵盖了从操作DOM、处理事件、存储数据到进行网络请求等各种功能。
使用js操作html和浏览器。
分为两大类：DOM和BOM

DOM(文档对象模型)Document Object Model

DOM（文档对象模型）是HTML和XML文档的编程接口。它将文档表示为一个节点树，开发者可以通过JavaScript对其进行操作。开发网页特效，操作页面元素。

DOM树

HTML文档被解析成一个树状结构，称为DOM树。每个HTML元素、属性和文本节点都对应DOM树中的一个节点。
例如，HTML中的` div`元素在DOM树中表示为一个元素节点，`p`元素也是一个节点，文本内容则是文本节点。
DOM树的根节点是`document`对象，它代表整个HTML文档。
DOM树的层级结构允许开发者通过亲子关系访问和操作节点。例如，可以通过`parentNode`属性访问亲节点，通过`childNodes`属性访问子节点。

DOM对象

DOM对象是JavaScript中表示HTML元素的对象。每个HTML元素在DOM中都有一个对应的对象，可以通过JavaScript代码访问和操作这些对象。
浏览器根据HTML文档创建DOM对象，开发者可以使用各种方法和属性来操作这些对象。
例如，`document.getElementById('myElement')`返回一个表示具有指定ID的HTML元素的DOM对象。
常用的DOM对象包括：

  • `document`：表示整个HTML文档。
  • `Element`：表示HTML元素，如`div`、`p`等。
  • `Node`：表示DOM树中的节点，包括元素节点、文本节点等。
  • `Event`：表示事件对象，用于处理用户交互事件。

获取DOM对象的方法：

根据css选择器获取：
`document.querySelector('css选择器')` 选择匹配的第一个元素
`document.querySelectorAll('css选择器')` 选择匹配的所有元素
根据id获取：`document.getElementById('id')`//不常用
根据类名获取：`document.getElementsByClassName('class名')`//不常用
根据标签名获取：`document.getElementsByTagName('tag名')`//不常用
