日期对象

JavaScript 提供了 Date 对象来处理日期和时间。Date 对象包含了与日期和时间相关的方法，可以用来获取当前日期、设置特定日期、格式化日期等。

实例化

在代码中发现new关键字，表示实例化一个对象。Date对象可以通过以下几种方式实例化：
1. const date = new Date()：创建一个表示当前日期和时间的 Date 对象。
2. const date = new Date(milliseconds)：创建一个表示自1970年1月1日以来经过的毫秒数的 Date 对象。
3. const date = new Date(dateString)：创建一个表示指定日期字符串的 Date 对象。
4. const date = new Date(year, month, day, hours, minutes, seconds, milliseconds)：创建一个表示指定日期和时间的 Date 对象。注意，月份是从0开始计数的（0表示1月，11表示12月）。

日期对象方法

Date 对象提供了许多方法来操作和获取日期信息，以下是一些常用的方法：
1. getFullYear()：返回四位数的年份。
2. getMonth()：返回月份（0-11）。
3. getDate()：返回月份中的某一天（1-31）。
4. getDay()：返回星期几（0-6）。
5. getHours()：返回小时（0-23）。
6. getMinutes()：返回分钟（0-59）。
7. getSeconds()：返回秒数（0-59）。
8. getTime()：返回自1970年1月1日以来的毫秒数。
9. setFullYear(year)：设置年份。
10. setMonth(month)：设置月份（0-11）。
11. setDate(day)：设置月份中的某一天（1-31）。
12. setHours(hours)：设置小时（0-23）。
13. setMinutes(minutes)：设置分钟（0-59）。
14. setSeconds(seconds)：设置秒数（0-59）。
15. toDateString()：将日期转换为字符串格式。
16. toTimeString()：将时间转换为字符串格式。
17. toISOString()：将日期转换为ISO格式的字符串。

时间戳

时间戳是指自1970年1月1日00:00:00 UTC以来经过的毫秒数。可以使用Date对象的getTime()方法获取当前时间的时间戳，或者使用Date.now()方法获取当前时间的时间戳。

算法:
将来的毫秒数 - 现在的毫秒数 = 剩余的毫秒数
剩余毫秒数 转换为 剩余时间的年月日时分秒
